A small workflow. A useful signal.

Check every new call
against your rules.

Secu statically compares the base branch with proposed changes. Set rules for protocol contracts, known wallet addresses, and trusted function names; inspect detected function signatures in the review. The analyzer and rules come from the trusted base revision so a pull request cannot rewrite its own review.
