The trust boundary

The model never becomes the security system.

The agent can plan, read public chain state, and produce a transaction proposal. It cannot alter policy, certify protocol health, bypass simulation, sign arbitrary messages, or touch the underlying provider.

EIP-7702 without blind trust

Persistent delegation gets a higher bar.

7702 is off by default. When explicitly enabled, WalletCordon recovers the authorization signer, binds wallet, chain, and next nonce, verifies the delegate’s live runtime code hash, rejects delegation chains, and requires the state diff to prove the exact code change.

Simulation catches malicious behavior in this transaction. Code identity protects against behavior that could emerge later under different callers or state.
