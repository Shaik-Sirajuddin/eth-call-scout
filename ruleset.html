Ethereum scan ruleset builder

Start from the bundled token and protocol map. Edit locally; no account or server required.

Ruleset controls

Choose which default registry entries the scanner may use, then add project specific addresses.

Risk terms

Blacklisted addresses are high risk. Unknown addresses are low-mid. Threshold checks apply to recognizable static swap slippage values.

Add a custom mapping

Custom mappings are written into the downloaded JSON ruleset. Address-only entries are treated as contracts unless assigned as tokens.

Premapped registry

Entries not found in a local ruleset are reported as unmapped by the analyzer. A registry match is an identity hint, not a safety guarantee.
