# Security policy

CallScout is security-sensitive software. Please report suspected vulnerabilities privately to the repository maintainers through GitHub's private vulnerability reporting feature when available.

Include the affected commit, component, impact, prerequisites, and a minimal reproduction using test keys and test networks. Do not include seed phrases, private keys, production RPC credentials, personal wallet information, or details that put live funds at immediate risk in a public issue.

This ETHGlobal prototype has not completed an independent audit. Use test wallets and bounded test funds. A passing CallScout decision is not a guarantee that a protocol or transaction is economically safe.

Public issues are appropriate for non-sensitive correctness bugs, documentation mistakes, and feature requests.
